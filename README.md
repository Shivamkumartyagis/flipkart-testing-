This project includes end-to-end mobile application testing performed on the Flipkart app. The testing covers multiple areas such as Orientation, UI, UX, and System Testing to ensure application quality, usability, and stability
Orientation Testing
Performed to verify that the application works correctly when the device orientation changes between portrait and landscape mode. Ensured that UI elements adjust properly, no data is lost, and the app does not crash during rotation.
Performed to validate all user interface elements such as buttons, text, images, layout, alignment, and responsiveness. Ensured that all elements are clearly visible, properly aligned, and consistent across different screens.
Performed to evaluate the overall user experience of the application. Focused on ease of navigation, smooth transitions, fast response time, and user-friendly interactions to ensure a seamless experience.
Performed to validate the application behavior under real-world conditions such as incoming calls, low battery, background/foreground switching, and network changes. Ensured the application remains stable and functional in all scenarios.
